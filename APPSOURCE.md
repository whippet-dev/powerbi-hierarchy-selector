## Summary

Filter related fields and hierarchy levels from one compact, accessible Power BI visual.

## Description

Multi-Field Selector gives report users one compact place to filter across
multiple related fields. Report authors can add fields in the required order
without first creating a formal Power BI hierarchy.

Use it for paths such as Region → Office → Team, Category → Product → Variant,
or Year → Month → Week. Compatible values remain easy to find while users
search, select individual values, or work with multiple branches and mixed
hierarchy depths.

### Key benefits

- Replace several separate slicers with one coordinated selector.
- Select across related fields and duplicate labels without losing identity.
- Use single-selection or multiple-selection behaviour.
- Search and sort each field independently.
- Preserve selections in saved reports and bookmarks.
- Work with external report filters and items with no data.
- Configure fonts, colours, spacing, wrapping and field containers.
- Use keyboard navigation, screen-reader labels and Power BI high-contrast
  themes.

Multi-Field Selector is free, requires no separate account, and does not send
report data or usage data to external services.

## Requirements and limitations

- Microsoft Power BI Desktop or Power BI Service.
- At least one grouping field.
- Relationships and filter direction configured appropriately in the Power BI
  semantic model.
- Field order determines the path shown by the visual.
