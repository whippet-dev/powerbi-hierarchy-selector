# Multi-Field Selector

**Multi-Field Selector** is a Power BI custom visual that lets report users select and filter across multiple related fields within one visual.

Add fields such as:

- Region → Office → Team
- Category → Product → Variant
- Service → Journey → Stage
- Year → Month → Week

The fields do not need to be configured as a formal Power BI hierarchy.

## Current features

- Multiple related fields displayed in one selector
- Context-aware values across fields
- Report filtering using Power BI filter APIs
- Selection persistence when reports are saved and reopened
- Bookmark support
- Clear all and per-field clear controls
- Configurable fonts, colours, spacing and containers
- Keyboard-accessible buttons and labels
